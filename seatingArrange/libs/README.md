# 智能班级排座系统 (纯离线单机版)

## 一、 项目背景与需求契合

本项目基于教师教学与日常排座管理实际需求开发，完全对照教师工作台标准排座系统实现，专为**无网环境、单机独立运行、敏感数据保密**等教学场景量身打造。

### 核心需求落地情况一览：
1. **纯离线运行 & 双击 HTML 访问**：
   - 全套技术栈采用纯离线前端体系，无需安装 Node.js、Python 或任何后台服务，不需要互联网连接；
   - 本地双击 `index.html` 即可在 Edge、Chrome、360 等主流浏览器中直接打开即用。
2. **多样式排座规格 & 4大组双人桌**：
   - 默认采用中小学最常用的**4大组·8列双人桌 (2+2+2+2)** 规格，每两个座位紧密挨在一起，大组之间自动保留标准走道；
   - 同时内置提供：3大组双人桌 (2+2+2)、5大组双人桌 (2+2+2+2+2)、单人单桌（6列/7列/8列独立走道）、三人同桌（3+3）、对称均等网格；
   - 支持排数（1~25排）与列数（1~20列）的任意自由增减调节。
3. **老师视角 vs 学生视角 自由切换**：
   - **学生视角**：以学生面向黑板视角呈现，讲台在最上方，第1排在最前，从左到右为第1组到第4组；
   - **老师视角**：以教师站在讲台面向全班学生视角呈现。讲台位于最下方，第1排离老师最近（位于最下方），最后一排在最上方（教室后黑板/后门）；大组与列左右自动镜像对齐老师肉眼视线，免除反向思考与脑补；
   - 两种视角下拖拽换座、点击对调、锁定等所有交互完全无缝兼容；导出图片时自动按选中的视角生成对应的讲台与座位朝向。
4. **班级历史记录备份管理 (版本快照与回滚)**：
   - 顶部工具栏提供【班级历史备份】面板，展示所有历史排座方案快照列表；
   - 支持随时录入备注（如“第4周大组平移后”、“期中微调”）生成当前排座快照；
   - 列表中直观展示方案名称、所属班级、备份时间、规格（行×列）、已就座/锁定人数；
   - 支持**一键恢复此排座**（无损回滚至任意历史版本）、**单独导出/导入**、**重命名备注**、**单独删除**及**清空历史**。
5. **座位锁与人员固定功能 (特殊关照座位)**：
   - 座位右上角由原性别圆点替换为【锁按钮】；
   - 点击锁定后即固定该学生及其物理座位，在执行按学号排座、男女同桌搭配、全班随机打乱、大组轮换及清空时，已锁定学生**始终固定在原座不变**，满足视力矫正、个别辅导等教学场景；
   - 支持单个点击锁按钮解锁，亦可在菜单中“一键解锁所有座位”。
6. **多格式导出能力**：
   - **高分辨率图片导出 (PNG)**：纯客户端原生 HTML5 Canvas 2x 超高清绘制，包含讲台黑板、大组指示、排号列号、男女生配色与图例水印，不受 `file://` 协议跨域污染限制，随时可打印张贴；
   - **DOM 网页视图截图导出 (PNG)**：采用集成在本地的 html2canvas 进行所见即所得截图；
   - **Excel 表格导出 (.xlsx)**：基于本地 SheetJS 库，生成包含“班级可视化座位表”与“学生花名册及座次明细”双工作表的标准 Excel 文件；
   - **纯文本导出 (.txt)**：自动生成对齐规整的字符画表格，方便复制到微信、QQ班级群公布。
7. **完整智能排座算法与大组轮换**：
   - 🎯 按学号顺序排座、👫 男女交替同桌搭配、🎲 全班随机摇号打乱、一键顺延填补空位；
   - ⬅️ 左轮换（第1大组平移至最右）、➡️ 右轮换（最右组平移至第1组）、↕️ 前后排轮换。
8. **完整文档与说明**：
   - 教师日常操作指南提供于 `操作说明.txt`；
   - 技术实现与工程设计说明提供于 `README.md`（及 `REAME.md`）。

## 三、 技术架构与实现原理

### 1. 纯前端离线单机架构
* **运行零依赖**：系统没有任何后端 API，所有状态响应由 Vue 3 浏览器端单文件直载驱动。
* **资源绝对本地化**：第三方库（Vue 3、SheetJS、html2canvas）、CSS 样式、矢量 SVG 图标全部打包在本地目录下，不发起任何针对外部 CDN 或字体服务的 HTTP/HTTPS 请求。
* **本地数据持久化**：
  * 使用 HTML5 `LocalStorage` 实现浏览器端实时持久化，所有增删改排操作毫秒级同步落盘；
  * `smart_seating_data_v2` 存储班级与当前座位表，`smart_seating_history_backups_v2` 存储历史版本快照序列；
  * 内置 `window.DEFAULT_DATA` 作为基础缺省保障。若首次在空浏览器环境下运行，自动载入完整的 42 人演示班级数据。

### 2. 视角坐标映射与大组走道算法
* **双视角空间变换模型 (`displayRows` & `displayGroupHeaders`)**：
  - 数据层保持单一真实二维矩阵 `currentClass.matrix[r][c]`；
  - **学生视角 (`student`)**：
    - 行从 `0` 到 `rows - 1`，列从 `0` 到 `cols - 1`；
    - 顶部呈现讲台与黑板，大组从左至右排列。
  - **老师视角 (`teacher`)**：
    - 行从 `rows - 1` 倒序至 `0`（离老师讲台最近的第 1 排位于界面最下方）；
    - 列从 `cols - 1` 倒序至 `0`（台下右侧学生呈现于老师左手边）；
    - 顶部呈现教室后门与后黑板，底部呈现讲台老师站位；
    - 所有点击、拖拽事件携带真实矩阵坐标 `(item.r, item.c)`，因此无需改动任何交互逻辑，天然防错。
* **大组与走道自适应间距算法**：
  根据视觉列索引 `visualCol` 动态计算 `getColMarginStyle(visualCol)`：
  - `double`（双人桌）：当列序号为奇数（`c % 2 === 1` 且非最后一列）时，自动赋予 `margin-right: 24px` 形成大组过道，偶数列之间为紧凑的 `6px` 课桌间距；不论正向还是镜像视角，过道位置完全对齐。

### 3. 班级历史记录备份系统
* **快照数据结构**：
  ```json
  {
    "id": "snap_1726456000000_abc",
    "name": "第4周大组平移后快照",
    "classId": "cls_1",
    "className": "三年级(1)班",
    "createdAt": "2026/09/16 03:30:00",
    "rows": 7,
    "cols": 8,
    "layout_mode": "double",
    "matrix": [[...], ...],
    "students": [...],
    "stats": { "total": 42, "seated": 42, "locked": 2 }
  }
  ```
* **版本恢复机制 (`restoreHistoryBackup`)**：
  恢复时完整复原矩阵网格、行列规格、走道布局，并自动同步补齐学生花名册，确保历史排座方案 100% 精确还原。
* **快照生命周期**：支持新建、重命名、恢复、单条删除、全量清空与导入导出。

### 4. 座位锁定与人员固定算法
* 在每个单元格对象中增加 `is_locked: boolean` 属性；
* **排座保护**：在执行自动排座或轮换时，先提取所有未锁定学生与未锁定坐标，算法仅在未锁定的坐标空间中重排，已锁定的坐标及其对应学生在整个过程中保持不动。

### 5. 导出引擎设计
* **原生 Canvas 高清图绘制 (`exportSeatingChartImage`)**：
  - 针对 `file://` 协议下安全策略，系统设计了基于原生 HTML5 2D Canvas 的独立排版渲染器；
  - 强制设定 `devicePixelRatio = 2`（超高清 Retina 标准）；
  - **自适应视角**：根据当前 `perspectiveMode` 动态调整讲台位置（顶部黑板 vs 底部讲台老师站位），并镜像绘制各列座位与大组名称；
  - 包含班级标题、大组指示、排号、男女生配色与锁定角标，直接可清晰打印张贴。
* **Excel 多工作表导出 (`exportToExcel`)**：
  - 调用 `xlsx.full.min.js` 的 `aoa_to_sheet`；
  - **Sheet 1 (班级可视化座位表)**：包含讲台合并表头、各组列名、以及排布形式的完整二维表格；
  - **Sheet 2 (学生花名册与座次明细)**：记录学号、姓名、性别、对应排号、列号、职务、打卡状态等，方便教务存档。
* **纯文本 TXT 导出 (`exportToTxt`)**：
  - 生成整齐对齐的走道隔断字符图，使用 Windows 记事本直接打开排版整齐。

## 四、 兼容性与运行环境

* **操作系统**：Windows 7/10/11、macOS、Linux、统信 UOS、麒麟等国产操作系统。
* **浏览器要求**：支持 Microsoft Edge、Google Chrome、360安全/极速浏览器、Firefox、Safari 等任意现代浏览器。
* **启动方式**：无需启动命令，鼠标双击 `index.html` 即可运行。
