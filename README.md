# 🎓 TeacherTools - 教师教学与班级管理全能工具箱

一套专为教师、班主任及课堂教学设计的现代化、纯前端离线自包含工具套件。开箱即用，无需复杂配置，支持在任意浏览器中直接运行。

---

## 📦 项目模块清单

| 模块目录 | 工具名称 | 功能亮点与介绍 |
| :--- | :--- | :--- |
| [`countdown/`](./countdown/) | **创意倒计时精选工坊** | 包含 8 款主题风格（机械翻页钟、赛博朋克、拟物挂钟、禅意沙漏、紧张拆弹、火箭发射、下班倒数、里程碑），支持顶部自定义专注任务名、全屏模式与离线音效。 |
| [`rondomRollCall/`](./rondomRollCall/) | **课堂随机点名神器 1.0** | 课堂互动点名提问工具，操作简便，支持导入班级名单。 |
| [`rondomRollCall2/`](./rondomRollCall2/) | **课堂随机点名神器 2.0** | 豪华升级版！内置 15 款趣味动态主题（星空银河、幸运转盘、老虎机、盲盒、扭蛋机、赛车竞速、刮刮乐、吃鸡空投、弹幕爆炸、聚光灯黑板等）。 |
| [`seatingArrange/`](./seatingArrange/) | **班级座位编排神器 1.0** | 教师排座工具，快速排布学生座位，支持导出与查看。 |
| [`seatingArrange2/`](./seatingArrange2/) | **班级座位编排神器 2.0** | 智能化排座系统，支持男女搭配、视力身高偏好、固定同桌/排斥规则、一键打印与导出 Excel。 |
| [`studentLearn/`](./studentLearn/) | **趣味互动学习闯关** | 寓教于乐的互动学习网页，内置四年级神话大闯关等答题趣味挑战。 |
| [`taskManage/`](./taskManage/) | **学生任务管理系统 1.0** | 班级与学生日常任务分配、进度记录工具。 |
| [`taskManage2/`](./taskManage2/) | **学生任务管理系统 2.0** | 增强版任务看板与统计，配备详细教师操作手册与指引。 |
| [`playCode/`](./playCode/) | **代码练习沙盒** | 个人编程与交互功能扩展测试空间。 |

## 🚀 使用方式

- **极简离线运行**：所有工具均为标准 HTML/CSS/JavaScript 纯静态架构，直接用 Chrome、Edge、Safari 或任何现代浏览器双击对应目录下的 `index.html` 即可运行。
- **电子白板/大屏适配**：各工具均针对班级希沃白板、触摸一体机及普通投影仪进行了响应式适配，支持快捷键全屏展示（按 `F` 键或双击空白处）。
