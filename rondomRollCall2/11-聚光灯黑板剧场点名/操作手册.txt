【这个文件夹里有什么】
  index.html    ← 双击这个文件就能开始点名（推荐 Chrome / Edge 打开）
  班级名单.txt  ← 你的学生名单，可直接用记事本打开修改
  操作手册.txt  ← 就是本文件

【主题特色】
  实木边框的大黑板立在舞台正中，两束暖黄追光左右扫射。摇人时粉笔字在黑板上飞快翻页，喊停的一瞬两束光缓缓交汇成一点，粉笔伴着沙沙声一笔一划写出中选者的名字，粉笔灰在光柱里簌簌落下。
  关键词：黑板 · 追光灯 · 粉笔字 · 剧场

──────────────────────────────────────────────────────────
  一、三步开始点名
──────────────────────────────────────────────────────────
  1. 双击 index.html，用 Chrome 或 Edge 打开（360 极速模式也可以）。
  2. 点右上角【📝 名单管理】，把学生名单粘进去，点【保存并应用】。
  3. 点下方大大的【开始点名】按钮（或直接按空格键）开始，再按一次停止并揭晓。

  ※ 第一次打开请先随便点一下页面任意位置，浏览器才允许播放音乐。

──────────────────────────────────────────────────────────
  二、快捷键（全 15 套通用）
──────────────────────────────────────────────────────────
  空格 / 回车    开始点名 / 停止并揭晓
  1 ~ 6          快速设置「每次抽取几人」
  R              重置本轮记录（名单不会被删）
  F              全屏 / 退出全屏（上课建议全屏）
  H              打开名单管理
  M              一键静音 / 恢复声音
  Esc            关闭弹窗 / 收起揭晓结果

──────────────────────────────────────────────────────────
  三、名单怎么改（三种方式，随便挑一种）
──────────────────────────────────────────────────────────
  方式 A · 直接编辑 班级名单.txt
     用记事本打开本文件夹里的 班级名单.txt，按下面格式改好保存：
         202401 张三
         202402 李四
         202403 王五
     回到网页 → 【📝 名单管理】→【📂 导入 txt】→ 选中这个文件 → 完成。

  方式 B · 在网页里手动输入 / 修改
     【📝 名单管理】里直接粘贴或一行行改，改完点【保存并应用】。

  方式 C · 从 Excel 表格导入
     在 Excel 里整理成「学号 姓名」两列 → 另存为「文本文件(制表符分隔)(*.txt)」
     → 再用方式 A 导入。姓名和学号之间是 Tab 也能正确识别。

  名单格式说明：
     · 每行一位同学，格式为「学号 姓名」；
     · 学号和姓名之间用 空格 / 逗号 / 顿号 / Tab 分隔都行；
     · 只写姓名不写学号也可以，系统会自动编号 01、02、03…；
     · 以 # 开头的行是注释，会被自动忽略，可以用来写「高二(3)班」这类备忘。

  ★ 名单是存在浏览器里的，改一次，本机 15 套模板全部同步生效。
  ★ 换电脑或换浏览器后名单不会跟过去，这时用【📂 导入 txt】重新导入一次即可。
  ★ 想彻底带走名单：点【📦 导出 HTML(名单已内嵌)】，会生成一份名单已经写死在里面的
    网页，拷到任何电脑双击打开，名单都还在。

──────────────────────────────────────────────────────────
  四、抽取规则
──────────────────────────────────────────────────────────
  · 每次抽取人数：下拉框选 1~6 人，也可以直接按数字键 1~6。
  · 不重复抽取：勾上（默认）后，本轮内点过的同学不会再被点到；
    全班点完一轮会自动弹出提示并开启新一轮，不用手动重置。
    取消勾选则每次都可能重复点到同一位同学（适合反复抽同一批人）。
  · 底部横条会记录本轮已点到的同学，按 R 可清空重新开始。

──────────────────────────────────────────────────────────
  五、声音与画面
──────────────────────────────────────────────────────────
  🎵 氛围音  本主题专属的背景音乐（Lo-Fi 爵士，三角波 Pad 铺底 + 摇摆鼓组，像午后教室的粉笔灰），
             可随时开关。上课时调小电脑音量即可，不影响其它操作。
  🔊 音效    点名前的倒数蓄力音、摇人时的加速脉冲声、抽中时的庆典号角，
             三段声音层次分明，学生能清楚听出「要抽了 / 正在抽 / 抽中了」。
  关闭声音：按 M 键或点右上角【🔊 音效: 开】。

──────────────────────────────────────────────────────────
  六、屏幕适配（14 寸笔记本已专门优化）
──────────────────────────────────────────────────────────
  · 已按 1280×720 及以上的分辨率专门调校，14 寸笔记本（含 125%/150% 缩放）
    开箱即用，不会出现卡牌被切掉半张、按钮跑到屏幕外的情况。
  · 页面会自动按舞台可用空间重新排布元素，窗口拉大拉小都会自动重排。
  · 接到教室大屏 / 投影时，按 F 键全屏，效果最佳。
  · 如果浏览器缩放不是 100%，请按 Ctrl+0 恢复默认缩放。

──────────────────────────────────────────────────────────
  七、常见问题
──────────────────────────────────────────────────────────
  Q：没有声音？
  A：浏览器规定必须先有一次点击才允许播放声音。随便点一下页面，
     或按一下空格键即可。另请检查电脑音量、以及右上角是否为「音效: 开」。

  Q：名单改了，另一套模板没变？
  A：请确认两次都是在同一个浏览器里打开的（例如都用 Chrome）。
     实在不行就在这套模板里重新【导入 txt】一次。

  Q：一不小心点了「恢复默认」，我自己的名单没了？
  A：恢复默认只影响浏览器里存的名单，你的 班级名单.txt 文件不会被改动，
     重新导入一次即可。建议平时保留一份 班级名单.txt 作为底稿。

  Q：能放到 U 盘 / 发给别人用吗？
  A：可以。整个文件夹拷走即可，无需安装任何软件、无需联网。

  Q：投影到大屏后字太大或太小？
  A：按 Ctrl 加 + 或 Ctrl 加 - 微调浏览器缩放，或按 F 全屏后按显示器实际
     分辨率调整。页面本身会自适应，一般不需要手动调。
