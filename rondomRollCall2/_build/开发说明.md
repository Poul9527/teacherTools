# 课堂随机点名 v2 · 开发说明

> 这个 `_build` 文件夹是**开发工具**，不是交付内容。
> 交付给老师的是根目录的 `index.html`、`操作手册.txt`、`班级名单.txt`，
> 以及 15 个 `NN-主题名/` 文件夹（每个里面也是这三个文件）。
> 打包发出去时可以把 `_build` 排除掉。

---

## 一、为什么要用构建脚本

15 套主题共用同一套内核（名单管理 / 音效引擎 / 特效引擎 / 快捷键 / 屏幕适配），
差别只在**视觉与玩法**。如果每套都手写一遍，改一个 bug 要改 15 个文件。

所以这里采用「**一份内核 + 15 份主题配置 → 构建成 15 个独立单文件 HTML**」的方式：

- 每套主题最终产出的 `index.html` 是**完全独立、可单独售卖/分发**的单文件，
  不依赖任何外部 JS / CSS / 音频 / 网络。
- 内核改一次，`node _build/build.js` 重跑，15 套全部同步更新。

## 三、常用命令

```bash
# 重新构建全部 15 套 + 合集
node _build/build.js

# 屏幕适配体检（1280×720 / 1366×768 / 1536×864 / 1920×1080）
node _build/verify.js

# 体检 + 出截图（存到 _build/shots/）
node _build/verify.js --shots

# 体检 + 模拟一次完整抽取，检查揭晓态也出屏
node _build/verify.js --roll --shots

# 只体检某几套
node _build/verify.js --only=04
node _build/verify.js --only=1        # 1 开头的一批

# 单套功能端到端测试（名单解析/导入导出/1~6人抽取/跨页同步/HTML 往返）
node _build/functest.js 04

# 全部主题做「导出内嵌名单的 HTML → 重新打开」往返检查
node _build/functest.js --all
```

`verify.js` / `functest.js` 会自动找本机 Chrome 或 Edge，找不到就退出。
它们**每次随机换调试端口**并用全新临时 profile，所以不会读到上一次的 localStorage。

## 四、新增一套主题

1. 复制 `themes/01.js` 和 `themes/01.stage.js`，改名成比如 `themes/16.js` / `themes/16.stage.js`。
2. 改 `meta`：`dir`（如 `16-某某点名`）、`title`、`badge`、`icon`、`accent`、`accent2`、`desc` 等。
3. 改 `css`（以 `:root{--accent:...}` 开头覆盖主题色）和 `body`（舞台 HTML）。
4. 改 `stage.js` 里的钩子函数。
5. 把 `16` 加进 `build.js` 顶部的 `THEMES` 数组。
6. `node _build/build.js`，然后 `node _build/verify.js --only=16 --roll --shots` 看效果。

### 主题文件的两条硬性约束

- `NN.js` 里的 `css` / `body` 是 JS 模板字符串，**内部不能出现反引号和 `${`**。
- `NN.stage.js` 会被原样拼进 `<script>`，**不能出现 `<script` 或 `</script`**。
  构建脚本会检查并在违反时直接报错。

### 一个容易踩的坑

导出「名单已内嵌的 HTML」时，构建好的页面会把所有带 `data-dyn` 属性的容器**清空**再导出。
所以：

> **凡是被 `TC.$()` 拿到、后续要用 `appendChild` / `.style` 操作的静态元素，
> 都必须放在 `data-dyn` 容器外面。**

第一版 `01.stage.js` 就把流星光标 `#comet` 放进了 `data-dyn` 的星图容器里，
结果导出后重新打开时 `appendChild(null)` 抛错、整个星图建不出来。
`node _build/functest.js --all` 这个往返测试就是专门用来抓这类问题的。

### 主题舞台钩子（都在 `NN.stage.js` 里定义）

```js
stageInit()            // 初始化：建 DOM、启动背景动画
stageLayout()          // 尺寸变化时重排（重新调 autoFitGrid）
stageStartRoll()       // 开始摇人：起定时器，每跳一次调 TC.Music.sfxRoll()
stageStopRoll(winners) // 停止：清定时器、高亮中选者、主题专属局部特效
revealWinners(winners) // 揭晓浮层
stageClearReveal()     // 收起揭晓
onResetHook()          // 重置本轮
themedPillStyle(el)    // 底部历史记录胶囊的配色
```

> `stopRolling` 时内核已经统一做了**礼花 + 多层烟花 + 星光 + 震屏 + 三段音效**，
> 主题里**不要重复做全屏礼花**，只做自己的局部效果。

## 六、音乐引擎

每套主题一套独立 BGM，全部由 WebAudio 实时合成，**不依赖任何音频文件**。

```js
music: {
  bpm, root,            // root 是根音 MIDI：45=A2, 48=C3, 52=E3, 55=G3, 57=A3
  stepsPerBar,          // 16 = 4/4；12 = 3/4
  chords: [[0,7,12,19]],// 每小节一个和弦，4 个音，相对 root 的半音偏移
  pad:  { wave, vol, oct, dur, atk, cut },   // 铺底和声，氛围感来源
  bass: { pat, oct, vol, wave, dur, cut },
  arp:  { pat, wave, vol, oct, dur },        // pat 值是和弦音序号，0~3 一组，4~7 自动升八度，-1 休止
  lead: null,                                // 可选，结构同 arp，另有 extra 补半音
  drums: 'heart',       // none|four|waltz|swing|rock|march|trap|lofi|heart|shaker|taiko|clap
  drumVol, swing,
  reverb, delay, bells
}
```

`pat` 数组长度**必须整除** `stepsPerBar`。
`wave`：`sine` 空灵 / `triangle` 清亮 / `sawtooth` 厚实电子 / `square` 复古 8-bit。

### 三段式场景音效

| 时机 | 音效 | 实现 |
|---|---|---|
| 点名前 | 上升 Risers + 四声倒数钟 + 落点重击 | `Music.sfxPrepare()`，内核在开始点名时自动调 |
| 摇人时 | 音高随进度上扬的脉冲 + 定音鼓 + 镲 | `Music.sfxRoll(ratio)`，主题定时器里调 |
| 抽中时 | 号角 / 钟琴 / 锣 / 史诗合唱 / 街机金币 | `Music.sfxWin(flavor)`，由 `meta.sfx.win` 指定 |

## 七、名单数据

- 存储键：`CLASSROOM_ROLLCALL_V2_STUDENTS`（同时回写 v1 的
  `CLASSROOM_ROLLCALL_STUDENTS_GLOBAL`，所以 v1 那 15 套模板也能读到同一份名单）。
- 读取优先级：v2 键 → v1 键 → 页面内置的 `DEFAULT_STUDENTS_RAW`。
- 内置名单来源：`_build/default-roster.txt`，构建时注入每个页面。
- 格式：`学号 姓名`，分隔符支持空格 / 逗号 / 中文逗号 / 顿号 / Tab / 分号；
  只写姓名会自动编号；`#` 开头的行是注释。
- 跨页同步：`storage` 事件 + 窗口重新聚焦时比对。
- 页面上的「📦 导出 HTML(名单已内嵌)」会把当前名单写死进一份新 HTML 里，
  换电脑打开名单也不丢。
