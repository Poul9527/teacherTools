# 班级座位表排座神器 (纯前端离线旗舰版)

一款专为中小学及高校班主任、教师定制的**高颜值、纯前端、支持完全离线运行**的班级排座位与小组管理工具。深度复刻小红书同款布局与平移机制（学习自 `buju.jpg`），支持自定义行数列数、8 种快速布局模板、列布局表达式、指定列/行平移、大组轮换、超易点击的专属锁定热区、独立全屏小组编辑器、多班级存档以及纯净无注释的规范 Excel 与高清图片导出。

---

## 🚀 核心功能与亮点

### 1. 灵活的座位布局 (学习小红书 `buju.jpg`)
- **自由设置行列**：自由输入教室行数（如 6 排）与列数（如 7 列或 8 列）。
- **快速布局预设网格**：一键应用常见模板：
  - `2-2-2` (6列)
  - `2-3-2` (7列)
  - `2-3-3` (8列)
  - `3-3-3` (9列，三人桌)
  - `3-2-3` (8列)
  - `3-3-2` (8列)
  - `2-4-2` (8列)
  - `2-2-2-2` (8列)
- **自定义布局表达式**：支持输入如 `2-1-2-1` 等任意格式，点击「应用布局」即刻生成带过道的复杂布局。
- **画布背景无限延展**：背景纸张采用自适应宽度，大组增加时背景无限延展包裹，彻底解决背景不扩展问题。

### 2. 直观的座位平移 (学习小红书 `buju.jpg`)
- **列平移 (左右)**：
  - 支持指定列号（如输入 `1 2 3`，或单个列 `1`，或连续范围 `1-3`，或 `1组`）；
  - 留空默认对全班所有列整体循环平移；
  - 输入单个列（如 `1`）时智能与移动方向的目标列平移对调；
  - 可选「← 向左平移」与「→ 向右平移」，设定平移步数，点击橙色「执行平移」或方向按钮即刻生效。
- **行平移 (前后)**：
  - 支持指定行号（如输入 `1 2 3`，或单个行 `1`，或 `第1排`，或连续范围 `1-3`）；
  - 留空默认对全班所有行整体平移前后轮换；
  - 输入单排行号时智能与移动方向的目标排对调；
  - 可选「↓ 向后平移」与「↑ 向前平移」，设定平移步数，点击橙色「执行平移」或方向按钮即刻生效。
- **每周大组轮换**：支持一键向左或向右循环大组轮换，预防斜视。

### 3. 精致无框锁定按钮与独立排次标尺 (第1排、第2排...)
- **独立排次标尺**：左侧排次标尺采用标准阿拉伯数字【第1排】、【第2排】、【第3排】...标签，独立列布局，绝不遮盖或挤压第一列学生卡片与姓名，并随「显示排号」复选框自由开启/关闭；
- **精致无框无遮挡锁定**：锁头按钮采用透明轻巧设计，彻底去除外层多余边框与白色背景，不遮挡学生姓名文字；支持右上角专属快速点击锁定（🔒）或解锁（🔓）；
- **导出与打印自动去锁**：导出图片（PNG）与纸张打印时，系统自动移除锁定图标，输出最整洁美观的无干扰纯净座位表；
- **彻底拦截事件冒泡**：拦截 `mousedown`、`mouseup`、`dblclick`、`click`，杜绝误触卡片拖拽或对调，轻松点中；
- **去除底部“注：...”文字**：彻底移除底部的注释文字，输出的座位图与 Excel 纯净专业。

### 4. 规范名单解析与智能排座算法
- **标准格式解析**：支持 `学号 姓名 性别 [名次] [身高] [视力]` 或 `姓名 性别`，男女生统计 100% 精准。
- **排座策略**：完全随机、男女同桌、真正同性同桌（纯男男、女女搭档）、S型蛇形排座、成绩蛇形排座、身高前后排、以优带潜互助对、视力关照优先前排。

### 5. 独立全屏小组编辑器 (Group Maker)
- **区域自动分组**：设定行数和列数（如 2行×2列），系统自动将物理相邻座位聚类划分；
- **手动建组与管理**：自由创建小组、改名、解散；
- **跨组拖拽与批量分配**：支持未分组学生池多选批量移入，一键导出与复制小组名单。

### 6. 多班级数据存档与本地备份
- **本地班级快照**：支持保存、加载、删除多个班级数据；
- **JSON 文件导入导出**：可导出本地 `.json` 备份文件，随时恢复全套数据。

### 7. 师生双视角与规范导出打印
- **双视角**：支持【学生视角】与【老师视角】（讲台在下，座位倒转）；
- **规范 Excel 导出**：纯学生姓名（无 `(男)`/`(女)`），班级大标题、讲台和大组表头智能合并居中；
- **超清图片导出**：超清抗锯齿，自动过滤锁定按钮，纯净无瑕；
- **自适应横纵向打印**：系统智能计算座位表长宽比例，自动匹配最佳横向 (Landscape) 或纵向 (Portrait) 打印方向，并自动隐藏锁图标与操作按钮。

## 💡 使用方式

1. 双击 `index.html` 即可在电脑浏览器中完全离线运行。
2. 在「📐 布局设置」中设置行数列数，或点击「2-3-2」、「3-3-3」等快速布局一键应用。
3. 在「↔️ 座位平移」中选择列平移或行平移，输入指定行/列号（留空则为全班），点击橙色「执行平移」快速挪位。
4. 鼠标悬浮学生卡片右上角，点击专属小锁头（🔒）固定座位。
5. 点击「📊 导出Excel」或「🖼️ 导出图片」获取纯净座位表。
